Game Architect 10.0 - 核心 UI 系統鎖定版

遊戲類型 (嚴格約束底層邏輯)
視覺風格
1. 起始畫面與音效解鎖 (Start Screen)
強制實作絕對定位的 HTML Overlay，需點擊才能解鎖 Web Audio 權限並播放 BGM。
2. 大廳與說明介面 (Lobby & How to Play)
進入遊戲前的大廳，展示最高分、升級項目與詳細玩法說明。
3. 遊戲中暫停系統 (Pause & Resume)
支援 Esc 鍵或點擊 UI 暫停，並提供「繼續遊戲」與「返回大廳」按鈕。
4. 乾淨重置邏輯 (Clean Restart)
Game Over 或「返回大廳」時，程式碼必須清空畫布與所有陣列，嚴禁使用 location.reload()。
操作方式
啟動極致打擊感 (Juice)
包含螢幕震動(Screen Shake)、粒子爆破(Particles)與頓幀(Hitstop)。
